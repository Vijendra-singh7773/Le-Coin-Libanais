# Le Coin Libanais — Restaurant Website

A responsive, single-page restaurant website for Le Coin Libanais in Djibouti.

## Run locally
You can open `index.html` directly in a browser, or use VS Code's Live Server extension.

## Customize
- Edit restaurant copy, hours, address and phone in `index.html`.
- Replace images in `assets/` while keeping the same filenames, or update the image paths.
- Colors, typography and responsive layouts are in `styles.css`.

## Included
- Responsive navigation and mobile menu
- Hero section, restaurant introduction, menu cards, gallery and contact details
- Click-to-call phone link and Google Maps directions link
- User-provided restaurant photos
